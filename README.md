# 🏆 AI Жарыс: топтар сайысы

3 топқа арналған сұрақ-жауап ойыны (5 деңгей, 20 сұрақ). Бір ғана `index.html` файл. AI, сервер, build қажет емес.

## 1. GitHub-қа жүктеу
1. github.com → **New repository** (мысалы, `ai-contest`) → Create.
2. **uploading an existing file** сілтемесін басып, `index.html` және `README.md` файлдарын жүктеңіз → **Commit changes**.

## 2. Vercel-ге шығару
1. vercel.com → GitHub аккаунтымен кіріңіз.
2. **Add New → Project** → `ai-contest` репозиторийін таңдаңыз → **Import**.
3. Framework Preset: **Other**. Build Command мен Output Directory бос қалсын → **Deploy**.
4. Дайын сілтеме: `https://ai-contest.vercel.app` (немесе соған ұқсас).

Кейін `index.html`-ды GitHub-та өзгертсеңіз, Vercel сайтты автоматты түрде жаңартады.

## Жаңа ойын
Сайттағы **«Жаңа ойын»** түймесі ұпайды тазалайды.
